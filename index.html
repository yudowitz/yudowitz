Education for crime victims

How to read the Yudowitz source archive

This guide is for crime victims and other readers who need to organize documents so someone else can review the record. Start with the original source, preserve its wording, and keep your interpretation separate. The method maps what the record says. It does not decide guilt.

Keep four labels separate

Source
The original file and a precise location within it: its title, URL, PDF page and, where available, printed page, paragraph or exhibit number.
Reported
A statement made in the source. Record who made it and quote the relevant words before writing a summary. A reported statement is not, by itself, an independently established finding.
Inference
Your interpretation of one or more sources. Identify the source locations and explain the reasoning, so another reader can examine the same material.
Unknown
Information the available record does not establish. Write the unanswered question and what further source would help address it.

Read document labels with care

The index above uses labels such as complaint, affidavit, exhibit, supplemental filing and cover letter. Use these labels to navigate, then check each PDF for its exact title, author, date and stated status. A filename is not confirmation of receipt, notarization, acceptance or an outcome.

Keep an earlier document alongside a later correction or supplement. Identify exactly which passage the later source addresses. Do not silently replace the earlier wording or assume every later file changes every earlier statement.

Make a note another reader can check

  1. Record the source title and stable link. Keep the original file unchanged.
  2. Record the relevant date exactly as shown. Distinguish the date of an event from the date of a document; label an absent date unknown.
  3. Copy a short, exact quotation with its page or paragraph location. Put your summary in a separate field.
  4. Label the note source, reported, inference or unknown. Add links to any related correction, supplement or exhibit.

Note format: Source title and URL; PDF page / printed page / paragraph; date and what it dates; exact quotation; separate summary; label; related source; unanswered question.

The same statement repeated across several documents is not automatically independent corroboration. Trace each repetition to its underlying source. A connection between people or events should remain an inference unless the cited record supports the specific relationship.
